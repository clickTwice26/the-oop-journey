🎯 Understanding Inheritance

🏠 The Family Tree Analogy

Think of inheritance like a family tree. Children inherit traits from their parents: eye color, height, talents. But they can also have their own unique features.

👨‍👩‍👧‍👦 Person (Parent Class)
name, age, speak()
👨‍🎓 Student
+studentId, study()
👨‍💼 Teacher
+subject, teach()
Java Implementation:
// Parent class
public class Person {
    protected String name;
    protected int age;
    
    public void speak() {
        System.out.println(name + " is speaking");
    }
}

// Child class inherits from Person
public class Student extends Person {
    private String studentId;
    
    public void study() {
        System.out.println(name + " is studying");
    }
}

// Student automatically gets:
// - name, age (inherited)
// - speak() method (inherited)
// - Plus its own study() method

♻️ Code Reuse

Write common code once in the parent class, reuse it in all child classes. No need to duplicate functionality!

🎯 Specialization

Child classes can add their own specific methods and properties while keeping the general ones from parent.

🔧 Maintenance

Update parent class once, and all child classes automatically get the changes. Easy to maintain and extend!

📝 Java Inheritance Syntax

🔑 The "extends" Keyword

// Basic inheritance syntax
public class ParentClass {
    // Parent class members
}

public class ChildClass extends ParentClass {
    // Child class inherits everything from ParentClass
    // Plus can add its own members
}
✅ What Child Inherits:
  • • All public methods
  • • All protected methods
  • • All public fields
  • • All protected fields
❌ What Child Doesn't Inherit:
  • • Private methods
  • • Private fields
  • • Constructors
  • • Static methods (different behavior)

🔗 The "super" Keyword

📞 Calling Parent Constructor
public class Vehicle {
    protected String brand;
    protected int year;
    
    public Vehicle(String brand, int year) {
        this.brand = brand;
        this.year = year;
    }
}

public class Car extends Vehicle {
    private int doors;
    
    public Car(String brand, int year, int doors) {
        super(brand, year);  // Call parent constructor
        this.doors = doors;
    }
}
🔄 Calling Parent Methods
public class Animal {
    public void makeSound() {
        System.out.println("Some animal sound");
    }
}

public class Dog extends Animal {
    @Override
    public void makeSound() {
        super.makeSound();  // Call parent method
        System.out.println("Woof! Woof!");
    }
}

// Output:
// Some animal sound
// Woof! Woof!

🚗 Complete Vehicle Example

// Base class
public class Vehicle {
    protected String brand;
    protected String model;
    protected int year;
    protected double price;
    
    public Vehicle(String brand, String model, int year, double price) {
        this.brand = brand;
        this.model = model;
        this.year = year;
        this.price = price;
    }
    
    public void start() {
        System.out.println(brand + " " + model + " is starting...");
    }
    
    public void stop() {
        System.out.println(brand + " " + model + " has stopped.");
    }
    
    public void displayInfo() {
        System.out.println("Vehicle: " + year + " " + brand + " " + model + " - $" + price);
    }
}

// Derived class
public class Car extends Vehicle {
    private int doors;
    private String fuelType;
    
    public Car(String brand, String model, int year, double price, int doors, String fuelType) {
        super(brand, model, year, price);  // Initialize parent
        this.doors = doors;
        this.fuelType = fuelType;
    }
    
    // Override parent method
    @Override
    public void start() {
        System.out.println("Inserting key...");
        super.start();  // Call parent implementation
        System.out.println("Car is ready to drive!");
    }
    
    // New method specific to Car
    public void honk() {
        System.out.println("Beep! Beep!");
    }
    
    // Override parent method with additional info
    @Override
    public void displayInfo() {
        super.displayInfo();
        System.out.println("Doors: " + doors + ", Fuel: " + fuelType);
    }
}

// Usage
public class Main {
    public static void main(String[] args) {
        Car myCar = new Car("Toyota", "Camry", 2023, 25000, 4, "Gasoline");
        
        myCar.displayInfo();  // Inherited + overridden
        myCar.start();        // Overridden method
        myCar.honk();         // Car-specific method
        myCar.stop();         // Inherited method
    }
}
🖥️ Expected Output:
Vehicle: 2023 Toyota Camry - $25000.0
Doors: 4, Fuel: Gasoline
Inserting key...
Toyota Camry is starting...
Car is ready to drive!
Beep! Beep!
Toyota Camry has stopped.

🌳 Types of Inheritance

1️⃣ Single Inheritance

One child class inherits from one parent class. This is the most common type.

Animal
Dog
public class Animal {
    protected String name;
    public void eat() {
        System.out.println("Eating...");
    }
}

public class Dog extends Animal {
    public void bark() {
        System.out.println("Woof!");
    }
}

📊 Multilevel Inheritance

A chain of inheritance: Child inherits from Parent, Grandchild inherits from Child.

Vehicle
Car
SportsCar
public class Vehicle {
    public void start() { /* ... */ }
}

public class Car extends Vehicle {
    public void drive() { /* ... */ }
}

public class SportsCar extends Car {
    public void turboBoost() { /* ... */ }
}

// SportsCar has:
// - start() from Vehicle
// - drive() from Car  
// - turboBoost() its own
