🎭 Understanding Polymorphism

🎮 The Game Character Analogy

In a video game, all characters can "attack", but each character type attacks differently: Warriors use swords, Mages cast spells, Archers shoot arrows. Same action, different implementations!

🎯 All characters can attack():
⚔️ Warrior: "Swings sword for 50 damage!"
🧙‍♂️ Mage: "Casts fireball for 40 damage!"
🏹 Archer: "Shoots arrow for 35 damage!"
🛡️ Tank: "Shield bash for 20 damage!"
// Base class
public abstract class Character {
    protected String name;
    protected int health;
    
    public abstract void attack();  // Each will implement differently
    
    public void takeDamage(int damage) {
        health -= damage;
        System.out.println(name + " takes " + damage + " damage!");
    }
}

// Different implementations
public class Warrior extends Character {
    @Override
    public void attack() {
        System.out.println(name + " swings sword for 50 damage!");
    }
}

public class Mage extends Character {
    @Override
    public void attack() {
        System.out.println(name + " casts fireball for 40 damage!");
    }
}

// Polymorphism in action
Character[] party = {
    new Warrior("Conan"),
    new Mage("Gandalf"), 
    new Archer("Legolas")
};

for (Character character : party) {
    character.attack();  // Each attacks differently!
}

🏃‍♂️ Runtime Polymorphism

  • • Method overriding
  • • Decided at runtime
  • • Uses inheritance
  • • Dynamic method dispatch
Animal animal = new Dog();
animal.makeSound(); // "Woof!"

⚡ Compile-time Polymorphism

  • • Method overloading
  • • Decided at compile time
  • • Same method name, different parameters
  • • Static method dispatch
add(1, 2);
add(1.5, 2.3);
add("Hello", "World");

🚗 Complete Vehicle Example

// Parent class
public class Vehicle {
    protected String brand;
    protected String model;
    
    public Vehicle(String brand, String model) {
        this.brand = brand;
        this.model = model;
    }
    
    // Method to be overridden
    public void start() {
        System.out.println(brand + " " + model + " is starting...");
    }
    
    public void stop() {
        System.out.println(brand + " " + model + " has stopped.");
    }
    
    // Method to be overridden
    public void accelerate() {
        System.out.println("Vehicle is accelerating...");
    }
}

// Child class 1
public class Car extends Vehicle {
    private int doors;
    
    public Car(String brand, String model, int doors) {
        super(brand, model);
        this.doors = doors;
    }
    
    @Override
    public void start() {
        System.out.println("Inserting key...");
        super.start();  // Call parent method
        System.out.println("Car engine started! Ready to drive.");
    }
    
    @Override
    public void accelerate() {
        System.out.println("Car accelerating smoothly on the road...");
    }
    
    // Car-specific method
    public void honk() {
        System.out.println("Beep! Beep!");
    }
}

// Child class 2
public class Motorcycle extends Vehicle {
    private boolean hasSidecar;
    
    public Motorcycle(String brand, String model, boolean hasSidecar) {
        super(brand, model);
        this.hasSidecar = hasSidecar;
    }
    
    @Override
    public void start() {
        System.out.println("Kick starting motorcycle...");
        super.start();
        System.out.println("Motorcycle engine roaring!");
    }
    
    @Override
    public void accelerate() {
        System.out.println("Motorcycle accelerating with a roar!");
    }
    
    // Motorcycle-specific method
    public void wheelie() {
        System.out.println("Doing a wheelie!");
    }
}

// Child class 3
public class Truck extends Vehicle {
    private double cargoCapacity;
    
    public Truck(String brand, String model, double cargoCapacity) {
        super(brand, model);
        this.cargoCapacity = cargoCapacity;
    }
    
    @Override
    public void start() {
        System.out.println("Starting heavy-duty truck engine...");
        super.start();
        System.out.println("Truck ready for heavy hauling!");
    }
    
    @Override
    public void accelerate() {
        System.out.println("Truck accelerating slowly with heavy load...");
    }
    
    // Truck-specific method
    public void loadCargo() {
        System.out.println("Loading cargo into truck...");
    }
}

📝 Method Overloading

🧮 Calculator Example

public class Calculator {
    
    // Method overloading - same name, different parameters
    
    // Add two integers
    public int add(int a, int b) {
        System.out.println("Adding two integers: " + a + " + " + b);
        return a + b;
    }
    
    // Add three integers
    public int add(int a, int b, int c) {
        System.out.println("Adding three integers: " + a + " + " + b + " + " + c);
        return a + b + c;
    }
    
    // Add two doubles
    public double add(double a, double b) {
        System.out.println("Adding two doubles: " + a + " + " + b);
        return a + b;
    }
    
    // Add two strings (concatenation)
    public String add(String a, String b) {
        System.out.println("Concatenating strings: " + a + " + " + b);
        return a + b;
    }
    
    // Add array of integers
    public int add(int[] numbers) {
        System.out.print("Adding array: ");
        int sum = 0;
        for (int num : numbers) {
            sum += num;
            System.out.print(num + " ");
        }
        System.out.println("= " + sum);
        return sum;
    }
    
    // Multiply with different parameter types
    public int multiply(int a, int b) {
        return a * b;
    }
    
    public double multiply(double a, double b) {
        return a * b;
    }
    
    public int multiply(int a, int b, int c) {
        return a * b * c;
    }
}

// Usage example
public class CalculatorDemo {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        
        // Different methods called based on parameters
        calc.add(5, 3);              // Calls add(int, int)
        calc.add(2, 4, 6);           // Calls add(int, int, int)
        calc.add(2.5, 3.7);          // Calls add(double, double)
        calc.add("Hello", "World");   // Calls add(String, String)
        calc.add(new int[]{1,2,3,4}); // Calls add(int[])
        
        System.out.println(calc.multiply(3, 4));       // int version
        System.out.println(calc.multiply(2.5, 4.0));   // double version
        System.out.println(calc.multiply(2, 3, 4));    // three parameter version
    }
}
✅ Valid Overloading:
  • • Different number of parameters
  • • Different parameter types
  • • Different order of parameter types
❌ Invalid Overloading:
  • • Only return type different
  • • Only parameter names different
  • • Only access modifiers different
