📖 Definition

Encapsulation bundles data and methods while restricting direct access to internal components.

Two Pillars:
  • 🎁 Bundling: Data + Methods together
  • 🔒 Hiding: Restrict direct access

🎯 Benefits

  • 🛡️Data Protection
  • ✅Data Validation
  • 🔧Easier Maintenance
  • 🎛️Controlled Access
  • 🐛Reduced Bugs

🔐 Access Control Levels

🔒 Private

Only accessible within the same class

class Account:
  def __init__(self):
    self.__balance = 0 # Private

🔓 Protected

Accessible within class and subclasses

class Account:
  def __init__(self):
    self._balance = 0 # Protected

🌐 Public

Accessible from anywhere

class Account:
  def __init__(self):
    self.account_id = 123 # Public

⚙️ Getters & Setters

❌ Without Encapsulation

class Account:
  def __init__(self):
    self.balance = 1000
# Direct access - dangerous!
account.balance = -500 # 😱

✅ With Encapsulation

class Account:
  def __init__(self):
    self.__balance = 1000
  def get_balance(self):
    return self.__balance
  def deposit(self, amount):
    if amount > 0:
      self.__balance += amount

💻 Real-World Examples

🚗 Car Class Example

class Car:
  def __init__(self, make, model):
    self.__engine_running = False # Private
    self.__fuel_level = 100 # Private
    self.make = make # Public
    self.model = model # Public
  def start_engine(self):
    if self.__fuel_level > 0:
      self.__engine_running = True
      return "Engine started!"
    return "No fuel!"
