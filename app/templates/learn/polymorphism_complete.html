📖 Definition

Polymorphism allows objects of different types to be treated as instances of the same type through a common interface.

Greek Origin:
  • 📝 Poly: Many
  • 🔄 Morph: Forms

🎯 Benefits

  • 🔄Code Flexibility
  • 🔧Easy Extension
  • 📦Unified Interface
  • 🎭Dynamic Behavior
  • 🚀Runtime Decisions

🔄 Types of Polymorphism

⚡ Compile-time (Method Overloading)

Same method name, different parameters

class Calculator:
  def add(self, a, b):
    return a + b
  def add(self, a, b, c):
    return a + b + c
  def add(self, numbers):
    return sum(numbers)

🏃 Runtime (Method Overriding)

Same method signature, different implementations

class Animal:
  def make_sound(self):
    pass
class Dog(Animal):
  def make_sound(self):
    return "Woof!"
class Cat(Animal):
  def make_sound(self):
    return "Meow!"

💻 Real-World Examples

💳 Payment Processing System

class PaymentProcessor:
  def process_payment(self, amount):
    pass
class CreditCard(PaymentProcessor):
  def process_payment(self, amount):
    return f"Charged ${amount} to credit card"
class PayPal(PaymentProcessor):
  def process_payment(self, amount):
    return f"Paid ${amount} via PayPal"
class BankTransfer(PaymentProcessor):
  def process_payment(self, amount):
    return f"Transferred ${amount} from bank"

📁 File Processing System

class FileProcessor:
  def process(self, file):
    pass
class ImageProcessor(FileProcessor):
  def process(self, file):
    return f"Resizing image: {file}"
class VideoProcessor(FileProcessor):
  def process(self, file):
    return f"Compressing video: {file}"
class DocumentProcessor(FileProcessor):
  def process(self, file):
    return f"Converting document: {file}"
