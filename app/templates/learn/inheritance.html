🎯 What is Inheritance?

Inheritance is like a family tree in programming! Just as children inherit traits from their parents, classes can inherit properties and methods from other classes.

🌟 Key Benefits

  • ✓ Code Reusability
  • ✓ Saves Development Time
  • ✓ Easier Maintenance
  • ✓ Logical Organization

💻 Inheritance Syntax

Parent Class (Base)

class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def breathe(self):
        return f"{self.name} is breathing"
    
    def sleep(self):
        return f"{self.name} is sleeping"

Child Class (Derived)

class Dog(Animal):  # Inherits from Animal
    def __init__(self, name, age, breed):
        super().__init__(name, age)  # Call parent constructor
        self.breed = breed
    
    def bark(self):
        return f"{self.name} says Woof!"
    
    def sleep(self):  # Override parent method
        return f"{self.name} sleeps in a dog bed"

Using the Classes

# Create instances
dog = Dog("Buddy", 3, "Golden Retriever")

# Use inherited methods
print(dog.breathe())  # "Buddy is breathing"

# Use own methods  
print(dog.bark())     # "Buddy says Woof!"

# Use overridden method
print(dog.sleep())    # "Buddy sleeps in a dog bed"

Parent Class (Base)

public class Animal {
    protected String name;
    protected int age;
    
    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    public String breathe() {
        return name + " is breathing";
    }
    
    public String sleep() {
        return name + " is sleeping";
    }
}

Child Class (Derived)

public class Dog extends Animal {
    private String breed;
    
    public Dog(String name, int age, String breed) {
        super(name, age);  // Call parent constructor
        this.breed = breed;
    }
    
    public String bark() {
        return name + " says Woof!";
    }
    
    @Override
    public String sleep() {  // Override parent method
        return name + " sleeps in a dog bed";
    }
}

Single Inheritance Example
class Vehicle:
    def start(self):
        return "Vehicle started"

class Car(Vehicle):  # Single inheritance
    def drive(self):
        return "Car is driving"
